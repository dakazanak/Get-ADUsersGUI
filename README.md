# Get-ADUsersGUI

> ⚠️ **Hinweis:** Dies ist ein Test-Repository. Es sollte nicht produktiv eingesetzt werden.

PowerShell WinForms GUI zum Auslesen und Exportieren von Active Directory Benutzern.

## Voraussetzungen

- Windows PowerShell 5.1+ oder PowerShell 7+
- RSAT-Modul `ActiveDirectory` installiert
- Zugriff auf einen Active Directory Domain Controller

## Direktaufruf

```powershell
irm "https://raw.githubusercontent.com/dakazanak/Get-ADUsersGUI/master/Get-ADUsersGUI.ps1" | iex
```
